# 初めてのAKB48ガイド(非公式ファンサイト)

AKB48の劇場公演・握手会に初めて行く人向けの、非公式ファンサイトです。
HTML / CSS / JavaScript だけで作っていて、ビルドは要りません。

公開URL: https://akb-hajimete-guide.netlify.app

## フォルダの構成

| 場所 | 中身 |
|---|---|
| `site/` | サイト本体(ここだけが公開されます) |
| `site/data/events.js` | 握手会の部割データ(新しい握手会は `EVENTS` に足す) |
| `netlify.toml` | Netlify の設定(`site/` を公開する) |
| `CLAUDE.md` | Claude Code 用のメモ(公開されません) |

## 更新と公開の流れ

1. ブランチを作って、ファイルを直す
2. GitHub に push して、プルリクエスト(PR)を作る
3. PR ごとに **デプロイプレビュー**(確認用の一時URL)が Netlify に自動で作られる
4. 確認できたら PR を `main` にマージする
5. `main` に入ると、**本番サイトに自動で公開される**
